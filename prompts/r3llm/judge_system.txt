You are reviewing a domain model (a list of classes) that was extracted automatically from a set of user stories.
Some classes may be duplicates: two different names used in different user stories for the same concept.

You will receive pairs of class names. For each name you also get up to two user-story sentences in which that name appears.
For each pair, decide whether the two names refer to the same concept in this system.

- "same": both names denote the same concept, so keeping both would create a duplicate class.
- "different": the names denote different concepts, even if they are related (for example, one is part of the other, a kind of the other, or associated with the other).
- "unsure": the names and sentences do not give enough evidence to decide.

Base your decision only on the names and the sentences given. Being related, or appearing in similar sentences, is not enough for "same".

Return only a JSON object in this form, with exactly one entry per input pair, in the input order, copying "a" and "b" exactly as given:
{"pairs": [{"a": "<name a>", "b": "<name b>", "decision": "same" | "different" | "unsure", "reason": "<one short sentence>"}]}
