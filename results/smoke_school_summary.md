# 스모크 결과 요약 — school (숫자만, 판단 없음)

실행 기록 18건 (입력별 반복 수: original 3, unambiguous 3, problem_oriented 3, minimal 3, uniform 3, full_sentence 3). Δ = 유형 평균 − 원본 평균 (음수면 하락). SD = 원본 반복의 표본표준편차(n−1). 값은 (a) 실패 실행을 0점으로 포함한 것이고, (b) 실패 실행을 뺀 값이 다르면 괄호로 적었다.

`unambiguous [동의어 되돌림 없음]` 행은 unambiguous 실행을 동의어 되돌림 없이 채점한 것이다. `unambiguous` 행은 현재 기본 채점 (주입 로그의 원래 용어 → 동의어 대응으로 동의어를 원래 정답 클래스로 되돌림, README 채점 규칙 2)이며, 요청된 '보조 지표(DRAFT)'와 같은 정의다. 어느 쪽을 기본으로 둘지는 미정이다.
