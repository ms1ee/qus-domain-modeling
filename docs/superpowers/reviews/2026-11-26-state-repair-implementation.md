## 구현 중 결정

- 요청한 기존 체크아웃에 미커밋 LM Studio 연결 작업이 있어 그대로 보존했다. 브랜치 초기화·커밋·병합은 하지 않았다. 추후 커밋 시 기존 작업과 이번 작업을 구분해야 한다.
- 도메인 모델 생성 전 상태를 만든 뒤 수정 루프에 전달할 수 있게 했다. 모델링 오류도 기록하지만, 실패 단계에 따라 일부 산출물만 있는 실험 폴더가 남을 수 있다.
- 수정 실험에는 저장된 검증만 집계하고 `--force` 재채점을 거절한다. 회차 근거 덮어쓰기를 방지하는 대신 새 측정에는 새 실행 이름이 필요하다. 이전 단일 생성 결과의 명시적 재평가는 유지한다.
- 미커밋 변경이므로 커밋 범위 대신 변경 전 스냅샷과 현재 파일의 차이를 리뷰했다. 누락 위험을 줄이기 위해 현재 모듈도 직접 검토하고 전체 회귀 테스트를 수행했다. 검증 원문은 `.superpowers/sdd/2026-11-26-state-repair/`에 보존했다.
